# URBAN FRONTIER | 総合都市デベロッパー テンプレート

プレミアムな総合不動産・都市デベロッパー向けの高品質コーポレートサイトテンプレートです。

## 特徴
- **ストーリーテリング型レイアウト**: 単なる物件紹介ではなく、都市の未来を描く壮大なビジョンを伝える構成。
- **圧倒的な没入感**: 高画質の都市・建築ビジュアル（Unsplash厳選フリー素材）を最大限に活かしたフルスクリーンデザイン。
- **洗練されたタイポグラフィ**: セリフ体とサンセリフ体のハイブリッド構成で、ラグジュアリー感と信頼性を演出。
- **シームレスなアニメーション**: 重力を感じさせないスムーズなパララックス効果やフェードインアニメーションを全ページに実装。

## ページ構成
- `index.html`: トップページ（ヒーローパララックス・企業理念）
- `about.html`: 企業情報（Our Vision, Company Data）
- `projects.html`: 開発プロジェクト紹介（Signature Works）
- `contact.html`: お問い合わせフォーム（スプリットレイアウト）

## デプロイメント
本リポジトリは GitHub Pages に最適化されており、メインブランチへ Push するだけで自動的にライブサイトとして公開されます。
